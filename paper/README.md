# Manuscript source

Release: `2026-10-14-submission-v2`.

The manuscript source is `cas-dc-template.tex`. The directory contains the
CAS class/style files, bibliography, Figure 1 asset, current figure exports,
and the compiled `figure_exports/Figure2.pdf` asset required by the manuscript
source. From this directory, run `pdflatex`, `bibtex`, and two final `pdflatex`
passes. The compiled PDF is included as a reference.

This source package validates manuscript packaging only. Exact experimental
reproduction still requires the private inputs described in the repository
README and `docs/REPRODUCTION_COMMANDS.md`.
