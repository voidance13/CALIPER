# Manuscript source

Release: `2026-10-11-submission-v1`.

The manuscript source is `cas-dc-template.tex`. The directory contains the
CAS class/style files, bibliography, Figure 1 asset, and Figure 2 source needed
for a clean local compile. From this directory, run `pdflatex`, `bibtex`, and
two final `pdflatex` passes. The compiled PDF is included as a reference.

This source package validates manuscript packaging only. Exact experimental
reproduction still requires the private inputs described in the repository
README and `docs/REPRODUCTION_COMMANDS.md`.
