# CALIPER: Locality-Aware Collaborative Local-Cloud RAG

This repository contains the public code and lightweight documentation for the CALIPER paper submitted to *Neurocomputing*.

Public release: `2026-10-14-submission-v2`.

CALIPER separates cloud question guidance from local evidence-grounded answering:

1. A cloud model receives the question and returns guidance.
2. Retrieval, the knowledge base, and evidence-grounded answer generation remain local.
3. A source router selects a specialized retrieval configuration.
4. An optional execution classifier bypasses collaboration for questions predicted to be locally answerable.

The locality boundary is narrower than a formal privacy guarantee: questions and returned guidance can still reveal sensitive information. This repository therefore uses **locality-aware local-cloud RAG**, not a claim of differential privacy, cryptographic protection, or regulatory compliance.

## Repository status

This is a cleaned public tree for the current frozen paper protocol. It is organized for reading and bounded reproduction. Large datasets, model weights, retrieval caches, cloud responses, per-question predictions, logs, and companion archives are intentionally excluded. Exact command templates are in `docs/REPRODUCTION_COMMANDS.md`.

Historical scripts are marked as legacy and are not the default entry points. The current root entry points default to the frozen Qwen3.5-9B/Qwen3.7-plus naming; machine-specific paths in table-aggregation scripts remain private and are documented as such.

## Frozen paper configuration

- Local generation model: `Qwen3.5-9B`.
- Cloud reference model: `Qwen3.7-plus`.
- Retrieval initialization: `bge-base-en-v1.5` embedder and `bge-reranker-large` reranker.
- Datasets: HotpotQA, MuSiQue, and 2WikiMultiHopQA.
- Execution thresholds: `0.974` / `0.978` / `0.977` for HotpotQA / MuSiQue / 2Wiki.
- Table 5: estimated end-to-end latency formed by per-question retrieval and generation timings under the documented protocol; it is not an integrated live measurement.
- Statistics: paired question-level bootstrap with 10,000 resamples and percentile 95% intervals, as documented in the manuscript and supplementary notes.

The current paper source is in `paper/cas-dc-template.tex`. The paper's tables and figures are not regenerated by importing arbitrary files from `results/`; they remain tied to the frozen source and manifests.

To compile the public manuscript source, run `pdflatex`, `bibtex`, and two final
`pdflatex` passes from `paper/`. The required CAS template files, bibliography, Figure 1 asset, current
figure exports, and the Figure 2 PDF used by the manuscript are included there. This checks source
packaging only; reproducing the reported numbers still requires the private
inputs listed above.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env            # Windows: copy .env.example .env
```

Fill local secrets and machine paths only in `.env` or an untracked config. Never commit them. A cloud API key is required only for live cloud calls; cached guidance can be used for protocol checks when the corresponding frozen artifact is available.

The public tree does not download datasets or model weights automatically. Place private resources outside the repository and point scripts to them through configuration. Do not upload those resources to GitHub.

## Security and data policy

Never commit:

- `.env`, API keys, authentication files, or provider responses;
- benchmark files or raw supporting evidence;
- model weights, fine-tuning checkpoints, FAISS indexes, or retrieval caches;
- per-question prediction JSON/JSONL, logs, or multi-gigabyte archives.

The `.gitignore` is intentionally conservative. Run a secret scan and a large-file scan before any push.

## Historical code

`legacy/` contains previous implementations, repair scripts, and compatibility code, including dated frozen-run and cache-rebuild provenance under `legacy/work/`. These files preserve provenance but may refer to superseded models, prompts, paths, or result protocols. Use current root scripts and the mapping above for the frozen manuscript.
